Scrivere un’applicazione Client/Server Multithreading in Java che implementi il seguente scenario:
Il Client invia una stringa di testo contenente una lettera dell’alfabeto americano e un numero, separati da spazio (es: C 6)
Il server risponde in maniera casuale con una tra le due seguenti stringhe: 
 “Colpito!”
 “Mancato, ritenta!” 
Prima di rispondere il server valida la correttezza della struttura dati ricevuta, se non valida, inviar al client una stringa vuota.

La comunicazione termina con l’invio, da parte del client, di una stringa vuota.
